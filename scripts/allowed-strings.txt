# Addresses check-build.sh accepts in a release binary, one per line.
#
# The claim this list supports is that the only things the binary can contact
# are the ones written here, each with a reason. A line without a reason does
# not belong here.

# VirusTotal, the one service the program talks to. It sends the SHA-256 of a
# file and reads back how many engines flag it.
https://www.virustotal.com/api/v3/files/
https://www.virustotal.com/api/v3/files
https://www.virustotal.com/api/v3/analyses/

# Tauri, wry and muda embed source comments and panic messages that cite their
# own issue tracker. They are text inside code, never fetched.
https://github.com/tauri-apps/muda
https://github.com/tauri-apps/tauri/issues/2549
https://github.com/tauri-apps/tauri/issues/8306
https://github.com/tauri-apps/wry/blob
https://github.com/whatwg/html/issues/7428

# Tauri's own IPC origin on Windows. Local to the process; never leaves the
# machine.
http://ipc.localhost

# A placeholder inside a dependency's test fixture.
http://dummy.test

# Namespace identifiers from XML and certificate handling: names that look
# like addresses, which nothing resolves.

https://www.w3.org
http://purl.org
https://purl.org
http://ns.adobe.com
